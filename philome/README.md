# philome · 遇见你的思想轮廓

用64句日常想法，描绘八种思想关注，与三位思想邻居相遇。在线体验：[philome](https://coihan.github.io/philome/)。

## 当前版本 v5

- 64句精炼陈述，现有题目17–22字符；七档圆点从“非常不同意”到“非常同意”，选择后自动继续。
- 八轴各八句，正向与反向各四句。每连续八句覆盖全部八轴，正反表述交错。
- 每轴覆盖不同情境、动机与使用方式：例如经验中的证据/来源/反例，原则中的普遍规则/承诺/行动限度，省察中的情感成因/自我审查/记忆与罪责。
- 支持上一题、回看回答、继续进度和重新测试，数字1–7对应从左到右的七档。
- 保留米白、墨紫、衬线字标与叠纸答题卡、大幅思想家肖像、默认叠加雷达及可下载总结PNG。报告保存当前对照人物，头像读取失败仍可生成。

八轴仍是：经验求证、概念思辨、自主选择、共同关怀、原则承诺、行动实践、内在省察、诗性想象。

## 计分与人物参考

回答编码0–6：0非常不同意、3中立、6非常同意。正向得分为回答值，反向为`6 - 回答值`；同轴八句相加后除以48，显示为0–100。模型根据实际题目覆盖数计算分母，不写死题数。

各轴分别整理本次回答的赞同侧重，可以同时较高或较低，不固定总分、不按个人最高项拉满。增加题数扩展了情境覆盖，但不等于完成了准确性验证；同一轴的平均仍会压缩题内差异。

20位人物有全新64项七档设计性参考回答，按具体题面和动机编写，用同规则产生原型再计算欧氏距离。参考回答不是人物真实答卷，也没有从旧版用户答案换算。设计依据与语义锚点见[版本说明](docs/measurement-plan-v5.md)。这些方法限制保留在文档，不在答题页加入长声明。

当前仍是固定题库与规则，不在运行时调用大模型。Codex参与开发的过程与应用自身计分应分别介绍。

## 运行与文件

使用原生HTML/CSS/JavaScript，可部署于GitHub Pages，不需要额外前端依赖或模型密钥。请通过静态服务器打开，例如 `python3 -m http.server 4173`。

- `index.html`、`styles.css`、`app.js`：界面、SVG雷达、Canvas报告与交互。
- `model-v5.js`：八轴定义、按实际覆盖数计分与匹配。
- `data/questions-v5.json`、`data/thinkers-v5.json`：当前64句与人物参考回答。
- `portraits/`：20位人物插画；素材记录见[生成记录](docs/portrait-generation.md)。

当前进度使用独立键 `philome-progress-v5`，只恢复64个合法0–6回答。不兼容的旧进度静默忽略，不删除旧记录，不显示迁移或重答提示。PNG标记题库v5。旧模型、数据和文档留作历史记录，当前页面不加载。

## 检查与课堂展示

运行 `node checks/model-check.cjs` 检查64句长度和唯一性、每轴4正4反、八轴穿插、0/100端点、多轴可同时高低、单题变化方向、20人参考回答无重合与可达。另用16句平衡夹具检查模型分母确实随题数计算，并检查迁移提示已移除。可达是程序构造检查，不是历史或心理测量验证。

完整答题约5–8分钟。展示时可先演示几句和自动继续，再打开提前完成的画像，说明一处共鸣和一处不同，下载总结图，最后讲解正反计分与人物参考回答。
