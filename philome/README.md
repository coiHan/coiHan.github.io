# philome · 遇见你的思想轮廓

从32个日常情境出发，选择更像自己的回应，展开八维思想星图，遇见三位与你呼应的思想邻居。项目由 Codex 辅助开发，可用于人工智能基础课的应用展示。

在线体验：[philome](https://coihan.github.io/philome/)。

## v3 的变化

- 32个场景，每题四种回应，选择后自动进入下一题；支持返回修改、回看选择、继续进度与重新测试，数字1–4和字母A–D均可选择。
- 八轴改为经验求证、概念思辨、自主选择、共同关怀、原则承诺、行动实践、内在省察、诗性想象。每轴整理的是本次选择中的相对关注侧重。
- 结果先展示三张大幅思想家肖像，再默认展开本人和最近人物的叠加雷达；三位人物可以直接切换，八项数值另有紧凑明细。
- 一键下载总结PNG，包含大幅肖像、当前雷达对照、完整八项数值、共鸣、不同侧重、反思问题、日期及题库版本。使用浏览器原生Canvas；头像无法读取时以文字替代。
- 保留20位哲学、心理学与文学思想人物。全部使用本题库的设计性参考选择产生原型，不沿用旧双极坐标。

## 文件与运行

页面使用原生HTML、CSS和JavaScript，无需安装依赖或配置模型密钥，可部署于GitHub Pages。

- `index.html`、`styles.css`、`app.js`：页面与交互、SVG雷达及Canvas报告。
- `model-v3.js`：八轴定义、计分与排序，同一模块也供检查脚本使用。
- `data/questions-v3.json`：32个场景与128个稳定选项ID。
- `data/thinkers-v3.json`：20份人物参考选择及肖像信息。
- `portraits/`：现有人物插画。

请通过静态网站服务器预览，例如在本目录运行 `python3 -m http.server 4173` 后打开对应地址。页面会读取两个同域JSON文件，因此不再建议双击本地HTML打开。

## 星图怎样产生

每个选项有一项主要关注（2分）和一项次要关注（1分），两项均有选项文字依据。每题八轴各出现一次；整卷各轴分别出现16次主关注、16次次关注。选项位置也严格配平：每一字母位置里，各轴各出现4次主关注和4次次关注，连续选择同一字母不会固定偏向某轴。

完整答卷总积分为96。每轴固定机会分母为48，所以 `vector[d] = raw[d] / 48`；图上用0–100线性刻度显示。八轴合计固定为200、平均25，表示个人内部的相对侧重；不按个人最高轴硬拉到100。均匀轮廓是允许的结果。

人物的32个参考选择用同一计分规则生成原型，再用欧氏距离排序前三位。这些参考选择是结合思想主题的解释性设计，不是人物真实答卷；不能把文献主题当作精确数字。运行时没有调用大模型。使用Codex开发的过程，与应用自己的固定规则应分别介绍。

[八维设计与计分审查](docs/measurement-plan-v3.md)解释了维度边界、相对偏好计分的限制及原型原则；[人物参考选择说明](docs/thinker-prototypes-v3.md)记录具体选择依据。旧v2的[审查记录](docs/measurement-plan.md)保留为历史文档，不能用于解释v3结果。

v3使用独立的进度键 `philome-progress-v3`，只恢复合法的v3选项ID。检测到旧v2进度时会提示题目已更新并从新题开始，不换算旧答案，也不删除旧进度。总结图标记v3。

## 检查

运行 `node checks/model-check.cjs` 检查32题/8轴/20人、选项与字母位置的均衡覆盖、固定分母、总积分、每轴0/100端点、合法参考选择、不同人物无重合及20人可达。可达性表示程序构造自洽，不代表历史准确性或人群验证。

## 5–8分钟展示建议

1. 用约1分钟介绍：把日常情境里的优先选择，整理为可解释的思想关注。
2. 用约1–2分钟现场回答三四题，展示四种回应、自动继续和返回修改。
3. 用约2分钟打开提前完成的结果，展示大肖像、叠加雷达的一处共鸣和一处区别，并保存总结图。
4. 用约1–2分钟说明：主要/次要关注如何计分、为何使用固定刻度、人物参考选择如何得到原型，以及Codex在开发中的实际作用。
5. 余下时间介绍后续方向：收集使用者对题意的理解反馈，完善情境和人物参考选择。
