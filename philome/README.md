# philome · 遇见你的思想轮廓

用32句日常想法，描绘八种思想关注，与三位思想邻居相遇。在线体验：[philome](https://coihan.github.io/philome/)。

## 当前版本 v4

- 每题一句简短描述，现有题目15–20字符；用七档圆点从“非常不同意”到“非常同意”回答，选择后自动继续。
- 支持上一题、回看回答、继续进度和重新测试，数字1–7对应从左到右的七档。
- 保留原Philome的米白、墨紫、衬线字标与叠纸答题卡；结果为大幅肖像、默认叠加雷达和可下载总结PNG。
- 三位思想家可直接切换，报告保存当前对照。头像读取失败时用文字替代，仍可下载。

八轴仍是：经验求证、概念思辨、自主选择、共同关怀、原则承诺、行动实践、内在省察、诗性想象。

## 计分与人物参考

每轴四句，正向与反向各两句；每连续八句覆盖全部八轴。回答编码0–6：0非常不同意、3中立、6非常同意。正向得分为回答值，反向为`6 - 回答值`；同轴四句相加后除以24，显示为0–100。

这些分数整理本次回答对各关注的赞同侧重，八轴分别计算，可以同时较高或较低，不固定总分、不按个人最高项拉满。v3的强制选择积分没有沿用到本量表。

20位人物各有一份新题库的32项七档设计性参考回答，用相同规则生成原型，再计算欧氏距离排序。参考回答由作品主题和条目语义作解释性编写，不是历史人物真实答卷，也不是经验证的测量结论；不能仅凭文献赋予精确分数。方法和人物依据见[版本说明](docs/measurement-plan-v4.md)。这些说明保留在文档，不在答题页加入冗长声明。

当前仍是固定题库与规则，不在运行时调用大模型。Codex参与开发的过程与应用自身计分应分别介绍。

## 运行与文件

使用原生HTML/CSS/JavaScript，可部署于GitHub Pages，不需要额外前端依赖或模型密钥。请通过静态服务器打开，例如 `python3 -m http.server 4173`。

- `index.html`、`styles.css`、`app.js`：当前界面、SVG雷达与Canvas报告。
- `model-v4.js`：八轴定义、正反计分与匹配。
- `data/questions-v4.json`、`data/thinkers-v4.json`：当前题目与人物参考回答。
- `portraits/`：20位人物插画；新增素材记录见[生成记录](docs/portrait-generation.md)。

v4进度使用独立键 `philome-progress-v4`，只恢复32个合法0–6回答。v2/v3进度不换算、不删除，遇到旧进度只提示题目更新需重答。PNG标记题库v4。旧v3模型、数据和文档留作版本记录，不由当前页面加载。

## 检查与课堂展示

运行 `node checks/model-check.cjs`，检查32句长度、每轴正反覆盖、八轴穿插、0/100端点、多轴可同时高低、合法参考回答、20人原型无重合与可达。可达是程序构造检查，不是历史或心理测量验证。

现场可先演示几句短句和自动继续，再展示课前完成的结果，比较一处共鸣与不同、下载报告，最后用主要/反向条目和人物参考回答解释实现。完整答题约3–5分钟，课堂展示可控制在5–8分钟。
