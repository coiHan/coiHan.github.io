# philome · 遇见你的思想轮廓

从48句短句探索四组哲学立场，再循着具体问题对读思想家。在线体验：[philome](https://coihan.github.io/philome/)。

## 当前版本 v6

保留米白、墨紫、叠纸答题卡、大幅思想家肖像与七档赞同圆点。选择后自动继续，支持上一题、回看、继续进度、重测及下载PNG总结。键盘1–7对应从左到右的七档。

本轮从一般的性格、表达偏好和行动习惯，转向支撑判断的哲学理由。每组12句，两侧各6句，穿插呈现。

| 讨论的问题 | 两侧取向 |
| --- | --- |
| 知识根据 | 经验根据 ↔ 先验根据 |
| 伦理根据 | 后果理由 ↔ 义务约束 |
| 政治正当性 | 权利边界 ↔ 共同义务 |
| 意义根据 | 客观价值 ↔ 主体赋义 |

四组争论不是哲学的完整分类，尤其不把德性伦理、儒家、道家等复杂传统硬塞到某一组的中点。定义、题目标准与局限见[构念说明](docs/philosophical-framework-v6.md)。

## 回答与图谱

回答编码0–6，3为中立。分别计算每侧六句的平均认同，再以右侧平均减左侧平均生成[-1,1]的相对位置。系统同时保留两侧平均与中立回答数，所以两侧都认同、都保留、普遍中立以及其他混合回应能够分别描述。不能把同一相对位置都解释成“平衡”。

结果先展示四组立场与两侧认同摘要。图谱保留八个方向的视觉形式：四组争论各占一条直径，右端为(1+位置)/2，左端为(1-位置)/2。同组两端此消彼长，面积不表示能力、思想水平或哲学成熟度。

## 思想家对读

主结果不做完整人格的“最像谁”总排名。先按用户取向较清晰的问题，寻找该轴有文本依据且方向明确相同的思想家作为阅读线索，优先距离接近的人物，最多三位且不重复。中立、低认同或缺乏合适依据时允许少卡或不推荐；同等明确的轴按可对读程度排序。每张卡标明对读的问题。选择对照后，未知的思想家维度留空；图谱不跨缺失方向连线，也不把未知填成中立。

人物的参考回答是编辑性解释，不是真实答卷。逐轴依据、引用与不适宜编码的领域见[人物证据表](docs/thinker-evidence-v6.md)。文学家、精神分析等延伸人物保留在阅读线索中，不伪造四轴数字参与匹配。当前题目与参考坐标尚未经过样本校准或心理测量验证，程序检查不代表效度验证。

模型仍保留一个保守的全局距离函数用于内部检查与未来研究；界面使用逐维对读。应用运行时不调用大模型。Codex参与开发与应用自身使用规则计分应分别介绍。

## 文件与运行

原生HTML/CSS/JavaScript，可部署GitHub Pages，无需密钥或后端。通过静态服务器打开，例如 `python3 -m http.server 4173`。

- `index.html`、`styles.css`、`app.js`：答题、摘要、SVG对照与交互。
- `report-v6.js`：原生Canvas总结长图，保存点击时的立场与对照；头像加载失败也可生成。
- `model-v6.js`：四组定义、按实际覆盖数计分、缺失轴校验与逐轴人物候选。
- `data/questions-v6.json`、`data/thinkers-v6.json`：当前题库、逐题参考与来源注记。
- `portraits/`：现有插画；素材记录见[生成记录](docs/portrait-generation.md)。

当前进度键为 `philome-progress-v6`，只恢复当前题数的合法0–6回答。旧记录保留而不加载，答题页不出现迁移或重答提示。旧模型、题库与文档仅保留作历史记录，当前页面不加载。

## 检查与展示

运行 `node checks/model-check.cjs` 检查题数、两侧覆盖、极端与中立回应、每题变化方向、动态分母、人物缺失轴和逐轴对照。浏览器检查覆盖真实48次点击、自动继续、移动端溢出、结果恢复、人物切换与PNG下载。

课堂展示可先演示几句，再看四组立场摘要，选一位思想家讨论一处相近与一处差异，最后下载总结。方法解释应说明两侧分别认同及逐维对读，避免把四组坐标当作完整哲学身份。
