# philome · 你的思想邻居是谁？

通过 64 道日常情境题，把回答整理成八条思想坐标，再寻找与你相近的思想家。项目由 Codex 辅助开发，可用于人工智能基础课的应用展示。

在线体验：[philome](https://coihan.github.io/philome/)。

## 功能与运行

- 64 道题，每题七档同意程度；八个维度各有八道题。
- 从 20 位哲学、心理学与文学思想人物中，展示距离最近的三位，以及共鸣处、差异和八维坐标。
- 用八轴雷达图呈现思想倾向，可叠加最近思想家的轮廓作对照；每个维度仍有具体解释。
- 选择答案后自动进入下一题，末题选择后自动展开结果；支持返回修改、继续上次进度和重新测试，键盘数字 1–7 可选择答案。
- 使用原生 HTML、CSS 和 JavaScript，无需安装依赖或配置模型密钥。答案和进度保存在当前浏览器，计分在本地完成，答案不会上传。

`index.html` 是完整页面，`portraits/` 存放人物图像。可直接打开页面，也可通过静态网站服务器运行。

## 画像怎样产生

八条坐标分别是：认识世界、面对规则、人与他人、面对未知、判断对错、寻找意义、理解自己、表达真相。

每个选项先映射为 +3 到 −3 分，再乘以题目的正反方向标记。一个维度内八题的分数相加后除以 24，得到 −1 到 +1 之间的位置。八个位置组成个人向量。

系统把个人向量与 20 位人物预设的八维向量计算欧氏距离，按距离从小到大展示前三位。结果文字根据坐标、最接近的维度和差异最大的维度生成。

雷达图半径使用 `(坐标 + 1) / 2`：靠内对应维度左端，靠外对应右端，半径一半处是均衡参考环。它表达双极立场，不把面积或半径当成能力评分。

现有人物：苏格拉底、庄子、孔子、康德、尼采、萨特、亚里士多德、加缪、弗洛伊德、阿伦特、波伏娃、斯宾诺莎、陀思妥耶夫斯基、伍尔夫、鲁迅、博尔赫斯，以及本次补入的卢梭、笛卡尔、休谟、卡夫卡。

这里的 AI 应用主要体现在使用 Codex 辅助开发。运行时使用固定题目、预设人物向量和可解释的匹配规则，没有实时调用大模型，也没有训练人格预测模型。人物坐标是简化设定；结果用于思想探索，不是经过心理测量验证的诊断。

四张新增插画的提示词与处理记录见 [插画生成记录](docs/portrait-generation.md)。

题目与人物对应关系的修订依据见 [匹配审查记录](docs/matching-notes.md)。修改题意后使用新的题库版本，只恢复同版本的答题进度。

运行 `node checks/model-check.cjs` 可检查维度与正反题平衡、计分端点、人物素材完整性，以及各人物能否由有效答案匹配到。可达性属于程序检查，不代表现实人群的匹配准确率。

## 5–8 分钟展示建议

完整测试约需 10 分钟，建议课前先在展示用浏览器完成一次并保留结果，现场另开一个浏览器窗口或隐私窗口演示题目。

1. **约 1 分钟：介绍想法。** 希望把抽象的哲学倾向变成可互动、可解释的小应用。
2. **约 1–2 分钟：演示操作。** 现场回答两三题，展示七档选择、进度与返回修改。
3. **约 2 分钟：展示结果。** 切回提前完成的画像，叠加思想家雷达轮廓，讲解一处共鸣和一处差异。
4. **约 1–2 分钟：解释实现。** 回答如何变成八维向量、欧氏距离如何排序，以及 Codex 在开发中的作用。介绍个人实际参与的部分时，以自己的开发经历为准。
5. **约 30 秒：说明改进方向。** 例如调整题目表达、完善人物坐标和收集体验反馈。
