# 八维结果的解释与题库后续计划

审查日期：2026-10-28。针对题库版本 2（64 题、每维各 4 道正负方向题）。本次只提出审查方案，不改题目、不迁移旧答案。

## 立即交付：保留答案，拆开“偏向”和“认同”

问题首先出在信息压缩与中点解释，不应通过放大分数或强行二选一，让结果看起来更鲜明。现有程序的每维坐标，恰好等于两侧平均认同度之差：

```js
endorsement = (6 - answer) / 6; // answer: 0 很认同，3 中立，6 很不认同
leftMean  = mean(endorsement of p === -1);
rightMean = mean(endorsement of p === +1);
vector = rightMean - leftMean; // 与现有 scores() 完全等价
neutralCount = count(answer === 3); // 此维 8 题中选择中立的题数
```

例如，两侧都答“认同”、都答“不认同”、都答“中立”都会得到坐标 0。它们不能都被写成“你善于平衡两种方法”，更不能被说成“摇摆”“没有主见”。

建议主图采用 8 条固定的双端坐标，与默认思想家同时显示点位；用“相对偏向”，不用面积、能力值或排名。每条补充两侧的描述性认同标签，解释为什么落在这里。可用下面的界面分组规则，规则不是心理测量界限：

| 条件（按顺序判断） | 推荐文字 |
| --- | --- |
| `abs(vector) > .20` | `更偏向左/右`；可将 `.20–.50` 写作“略偏向”，更大写作“较偏向”，不写“极端” |
| 其余且 `neutralCount >= 6` | 本组多数选择中立，暂未归向某一端 |
| 其余且两侧均 `>= .65` | 两类描述都较认同；例如“经验观察与概念推演，你都较认同” |
| 其余且两侧均 `<= .35` | 两类描述认同都较少；本组描述可能没有覆盖你的主要做法 |
| 其余 | 本组暂未显示明显偏向 |

两侧标签可用 `>=.65 较多认同 / <=.35 较少认同 / 其余 认同程度居中`，避免给读者两个看起来像能力分的百分数。只从答案描述回答方式，不推断“善于兼顾”“随情境灵活切换”。若展示同侧题的最大最小差，只能称“本组回答有差异”，不能称“信度”“置信度”或据此判为无效答卷；不同题的情境本来就不同。

思想家坐标只有既有 `v`，没有真实答卷，不能虚构其两侧认同度。比较只对齐 `v`，给出“这条轴上更接近/相距更远”；分组标签只用于本人的作答。保持 0 坐标的两侧都认同、都不认同、全中立这三组，仍得到相同匹配，是现有一维差值模型的限制。补充解释能避免误读，但不能消除信息损失，也不能据此称匹配已经获得验证。

## 八维概念审查

下表是对当前条目内容的设计判断，不是已完成因素分析后的结构结论。

| 维度 | 可并存性与需要收窄的解释 |
| --- | --- |
| 经验观察 / 概念推演 | 完全可能同时重视；不同领域还可能采用不同知识路径。应说“本题中的优先路径”，不能直接宣布属于经验主义或理性主义学派。[SEP 的概述也强调这种分类的局限](https://plato.stanford.edu/entries/rationalism-empiricism/)。 |
| 共同规范 / 自主选择 | 可以共同支持；接受平等制定的约定本身可能体现自主。部分现题测到改革意愿或风险偏好，不能把守约等同服从权威。 |
| 共同体 / 个体 | 关系认同与独立目标可并存。帮助家人朋友也不自动等于共同体哲学；Q19、23 容易引出“善良”答案。 |
| 怀疑 / 确信 | 寻找可靠依据与在证据不足时暂缓判断可以同时成立。当前左右不完全是同一时刻的取舍；不能把谨慎当成终身怀疑论。 |
| 原则 / 结果 | 两者都可重视；只有具体冲突时才显出优先次序。Q38 也可能反映公平原则，而非结果主义。 |
| 发现 / 创造意义 | 可并存；Q46 的应变、Q48 的坚持还混入一般适应能力与自我效能。不要把积极应对自动解释成存在主义。 |
| 明确理由 / 隐含动机 | 可作为互补的解释层次。应统一为“解释行为时先追问什么”，不混成“作决定时理性还是感性”。 |
| 直接论证 / 故事想象 | 可以并用；当前题的场景不同，写议论文和表达心情自然会选不同工具，不能据此判断逻辑能力或文学天赋。 |

## 不建议这次直接全面换成二选一

“同一情境下，你更先做 A 还是 B”的双端七档，更直接问相对优先次序，可减少先后两道都认同后被相减的困惑；选项可以保留“无明显偏向”。但它会失去“两种都认同 / 都不认同”的绝对认同信息，且若 A、B 的成本和道德吸引力不同，仍有偏差。没有必要为让图形更尖锐而强制极端取舍。

当前最小有效修复是上述展示与解释。后续可先选经验/概念、原则/结果等 1–2 维制作匹配情境的 A/B 候选，用认知访谈检查读者究竟怎样理解，再决定全题库升级。[Pew 的问卷设计指引讨论了同意/不同意格式的迎合倾向、替代陈述格式、社会赞许与预试的重要性](https://www.pewresearch.org/writing-survey-questions/)。另须区分“相反方向的内容”与绕口的否定句：本库多数负向题不是语法否定，不能把所有负号题都当成有问题的反向题。[van Sonderen 等的原始研究提醒，简单混入反向措辞并不能保证消除迎合，可能增加误解；其特定疲劳量表研究不能直接证明本库存在同等效应](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0068967)。

单元检查只能验证题数、方向平衡、公式和旧答案兼容；两侧均值、离散程度、匹配距离都是程序描述指标。心理测量验证还需要真实受试者的理解访谈、条目表现、维度结构和重复作答等证据。本次没有这些数据，不把程序自洽写成验证成功。以上方法说明留在项目文档，不在网页加入用户已要求移除的声明。
