# v5：64 条短句与人物参考答卷

本版保持八种思想关注与七档认同选择，增加为 64 条交错短句。每轴八句、正反各四句；0=非常不同意、3=中立、6=非常同意。正向题记答案，反向题记 `6-answer`，每轴相加除以 48。各轴分别计分，不固定总分；可以同时较高或较低，不按个人最高轴拉满。

雷达表示对这些陈述的认同侧重，不是能力、群体百分位或互斥人格。增加题数提供更多表述与情境，不能单凭题数宣布结构、信度或区分度得到验证。固定八轴均值也会压缩同一轴内部的题目差异；人物的认识论、政治立场或文学形式不能全部由八个数概括。

人物参考答卷逐句按思想主题、作品关注与表达方式作设计性解释，保存 64 个整数，由同一模型计算坐标，不直接填写或微调浮点向量。作者参考不等于真实历史人物作答；文学作者不以小说人物的言论直接代替本人立场。合法答卷自匹配与原型互不重复，只证明程序可达，不等于历史或心理测量验证。

短句审查重点：只问一个关注；反向句描述同一关注的较少采用，避免把另一轴的优点塞进去；减少绝对措辞、道德褒贬与明显较正确的答案。正反配平不能保证消除迎合或理解偏差。方法背景沿用 [Pew 的问卷设计指引](https://www.pewresearch.org/writing-survey-questions/) 与 [van Sonderen 等的反向措辞研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0068967)。

人物背景资料与定性限制见 [既有审查记录](matching-notes.md)。下面的具体参考回应是编辑选择，不由文献直接推出。

## 实际检查

本次使用正式 `model-v5.js` 回放，20份64题答卷均合法，20个原型互不重复，每份答卷均唯一距离0匹配自身；八轴同时0、同时1及全中立0.5也已检查。当前最接近的两位设计原型是波伏娃与鲁迅，归一化欧氏距离约0.176；相近是可以接受的，不通过调小数或强行制造相反立场来拉开。距离仅作程序描述，不是相似性的统计置信度。

审题提出两处收窄：t43从“解释选择的线索”改为“作选择的依据”，使其回到原则优先；t45从“如何讲述经历”改为“怎样回看内在感受”，减少与诗性表达的混轴。题目ID、轴及方向不变，不影响参考答卷格式。
