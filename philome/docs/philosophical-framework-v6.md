# v6：从思考习惯改为哲学立场

建议采用 **48 条单句、七档同意程度、4 个问题各 12 题**。四维是选定哲学争论中的立场线索，不是四种能力，也不声称穷尽哲学。每维两侧各六条主张，分别保留认同度，再计算相对偏向。原有视觉可以保留，但不能以雷达面积或外扩解释“更强”。

## 为什么 v5 测偏了

| 旧题 | 实际更容易测到什么 | 哲学立场应追问什么 |
| --- | --- | --- |
| t06“遇到新说法，我想先知道它有哪些证据。”；t12“讨论有分歧时，我想先弄清关键词的意思。” | 求证与澄清的习惯。经验论者同样会推理，理性论者也会查证。 | 对现实的知识，是否必须最终依赖经验？理性能否独立提供某些认识？ |
| t30“面对难题，我想先找现在能改变的一步。” | 积极行动、问题应对。 | 行为正确的根据是什么？好的后果能否充分证明某种手段正当？ |
| t19“答应过别人的事情，我会把它当成行动的理由。” | 守约习惯，可能混入尽责性。 | 承诺是否具有不依赖最好后果的约束力？ |
| t01“重要选择，我希望由自己作最后决定。”；t10“作决定前，我会想谁的生活会受到影响。” | 个人自主愿望与关怀他人，并非一组政治对立。 | 公共权力凭什么限制个人选择？共同生活产生哪些非自愿义务？ |

## 四个推荐维度

### 1. 知识根据：经验根据 ↔ 先验根据

范围限定为**对现实世界的实质认识是否最终必须依赖经验，以及理性能否独立奠定某些认识**。经验根据一侧强调经验的必要性；先验根据一侧认可某些认识可以不靠感官经验成立。

禁止把它写成观察与逻辑、实际与聪明、科学与思辨的对立；“数学不靠观察成立”也不足以区分，因为经验论者可能承认数学与逻辑知识。知识来源、证成与日常工作方法不同，不能混写。不同领域还可能采取不同立场。[SEP 对理性论与经验论的界定及分类局限](https://plato.stanford.edu/entries/rationalism-empiricism/)。

例句方向：

- 经验侧：“纯粹思考不能独立告诉我们现实是什么样。”
- 先验侧：“有些关于现实的知识，无须感官经验也能成立。”

每侧六题分布在经验的必要性、现实判断的根据、理性独立认识的可能性三个子议题，不连续换词重复一句话。不要顺手把确信程度、喜欢抽象或对专家的信任放进本轴。

### 2. 伦理根据：后果理由 ↔ 义务约束

问题是**后果是否是行为正当性的最终根据，以及承诺、权利等能否构成独立约束**。后果侧不是自私，也不等于“多数人喜欢”；义务侧不是听权威、遵旧规或做事死板。规则后果论也会支持稳定规则，但支持它的理由是后果。[SEP 对后果主义及规则、承诺的讨论](https://plato.stanford.edu/entries/consequentialism/)。

例句方向：

- 后果侧：“行为是否正当，最终取决于它产生的总体后果。”
- 义务侧：“承诺即使没有带来最好结果，也有独立的约束力。”

这两句是方向示例，不是以一句代表整个学说。十二题覆盖承诺与违约、权利与整体利益、规则为什么值得遵守。两端都要有值得认真考虑的理由，不能一端写救人，另一端写机械办事。本轴没有覆盖德性伦理、关怀伦理等全部立场；同时不认同两侧也可能有实质哲学理由。

### 3. 政治正当性：权利边界 ↔ 共同义务

这是四轴中最需限制解释的一条。范围是**公共制度限制个人选择与要求非自愿义务时，什么构成正当理由**。权利侧强调平等的个人基本权利为共同决定设界；义务侧认可共同生活也能产生并非完全出于个人自愿的公共责任。

两者并非自由主义与威权主义的分界，也不是自由与善良的分界。自由主义内部就能同时重视基本自由、社会正义与公共义务；共同立法也可能被理解为自由的条件。因此结果只说在这些理由中怎样侧重，不能据此给人政治阵营标签。[SEP 对自由、社会正义及社群争论的说明](https://plato.stanford.edu/entries/liberalism/)。

例句方向：

- 权利侧：“共同作出的决定，也应受个人基本权利限制。”
- 义务侧：“共同生活可以产生并非个人自愿接受的公共义务。”

十二题分布在无害生活方式与公共规范、非自愿公共义务的根据、共同决定的权利边界三个子议题。共同义务不能靠“只要多数赞同就合理”来代表，权利不能靠“不管别人只做自己”来代表。愿意帮助朋友、服从家人、喜欢独处都不能作为计分替身。

### 4. 意义根据：客观价值 ↔ 主体赋义

范围是**生活意义是否至少部分依赖独立于个人认同的价值，还是最终由主体认同、选择与投入构成**。客观价值不等于上帝安排或预定宇宙目的；主体赋义不等于任性、享乐、乐观或“努力就有意义”。否认预设人生目的，也不自动等于否认客观价值。

确实存在同时要求主体投入与客观价值的混合观点，不能把它判成墙头草。[SEP 对意义的主观主义、客观主义与混合观点的区分](https://plato.stanford.edu/entries/life-meaning/)。该来源主要讨论当代分析哲学中的生活意义；与历史存在主义者的对应还需另外论证，不能直接给萨特、加缪贴同一标签。

例句方向：

- 客观侧：“某种生活有没有意义，并非完全由当事人的认同决定。”
- 主体侧：“生活意义的根据，最终来自主体自身的认同。”

十二题分别触及主体认同是否必要或充分、独立价值的地位、选择与投入的构成作用。要保留“必要”与“充分”的区别，不能把参与一项自己认可且有价值的事业当作纯粹任一端的独占表现。

## 编题与计分约束

- 每题是一条可争辩的主张或理由；优先“应当、取决于、即使、足以、独立于”等有明确逻辑范围的表述。减少“我常、我喜欢、我先做”等习惯句。
- 每维两侧各六题，不靠生硬语法否定凑反向；两侧可以分别提出正面理由。每题只测一个争点，避免双重主张。
- 先写明题目限定的领域、条件及必要/充分关系，再缩成短句；不能为短而丢掉决定立场的条件。措辞尽量简短，但不强行统一字数。
- 48题中交错四个维度与两侧方向；不要把所有同侧题放在同一段。覆盖配平只是程序检查，不是维度结构或效度验证。

若回答为0–6，则每侧认同度是本侧六题的 `answer/6` 均值，记为 `L`、`R`；相对方向为 `R-L`。仅为图表需要，可线性映射到 `[0,1]`，但保留原始两侧均值，不拉伸分数，也不把大小称能力。

## 中间分数怎样解释

相对方向接近零，只说明两侧平均认同接近，不自动说明均衡、温和、犹豫或没有主见：

| 回答模式 | 可以表达的结论 |
| --- | --- |
| 两侧都较认同 | 同时接受两类理由；展示最认同的两条主张。它可能构成混合立场，也可能有待澄清的张力，不能自动赞成其逻辑一致。 |
| 两侧都较少认同 | 这组争点尚未涵盖其主要理由，或其拒绝两种给定立场；不能当作两者折中。 |
| 多数选中立 | 尚未在这些陈述上表达明确立场，不能推断成熟的中道哲学。 |
| 两侧有不同场景的高低 | 在具体子议题中存在差别，可选一对实际回答解释；不能称测出了情境灵活性或统计置信度。 |

如使用 `.65/.35` 等文案阈值，应只把它们视为界面分组，不能冒称学术分界。建议优先展示“你更认同哪条理由”，让读者看到差别的内容。

## 人物与阅读对应

主结果应先回答四个哲学问题，人物作为“可对读的思想家”或“阅读回声”。没有文献依据的轴保留未知，不填中间值；已知轴很少的人也不能因为只比较了一项，就自动成为最接近的人。人物雷达上的未知轴同样应留白，不能画成已知中间立场。

尼采可能同时拒绝简单后果论与义务论；康德、卢梭等人的自由与共同义务也不能靠一条人格轴概括。文学作者或心理学家在这四个问题上未必有可重建的完整立场，可以保留大肖像与相关问题的阅读说明，不必硬造四维参考答卷。比较时至少保留两侧认同模式，避免把“同时接受”与“同时拒绝”都折叠成同一个人物坐标。

本轮最终采用逐维对读：从表达较明确的三个问题中，各选一个在该问题上有来源支持的人物，不再给全部人物排整体相似名次。每卡指出相关轴、对应理由及一个可继续追问的问题；这不是一个人格类型的三位代表。人物所缺的轴继续保持未知。

若不足三个问题有明确表达，或某一问题没有适合的可靠人物，宁可少给对读卡，或提供明确标注的相关阅读；不要为了固定三张头像而降低来源标准。依据覆盖、文案分组阈值与卡片选择规则都属于产品设计，不是概率、信度或心理测量验证。

八方向雷达可以将四个方向差分别画为一组对径的 `0.5±0.5×方向差`。此图显示相对位置，两端长度不是两侧绝对认同，也不是独立的八个分数；左右认同与回答模式必须另行保留。固定的互补画法会约束轮廓面积，因此不能根据面积或某一端较长评价思考成熟度。

选择四维而非五维，是因为48题能均匀覆盖四个核心问题。加入第五维并非不可能，但需要新的明确争点与重新配题；不要仅为多一个雷达角，追加未经澄清的“自由意志/决定论”或“现实/理想”等假对立。
