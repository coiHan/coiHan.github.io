# v4 短句认同式画像

本版按用户的新要求，采用 32 条简短陈述与七级认同选择，取消情境四选一。0=非常不同意、3=中立、6=非常同意。八轴沿用经验求证、概念思辨、自主选择、共同关怀、原则承诺、行动实践、内在省察、诗性想象；每轴四句，正反方向各二句。

正向题计答案本身，反向题计 `6-answer`。每轴四题相加再除以 24，八轴分别计分，没有固定总和，可以同时较高或同时较低。雷达表示这些陈述中的认同侧重，不是能力、百分位或互斥人格类型。不存在“必须有一条满格”的规则，也不为让轮廓尖锐而拉伸分数。

v4 的结构更贴近简短的同意程度测试，但不表示它采用了 MBTI 的构念、题库或验证方法。正反配平只说明计分覆盖；不能证明消除了迎合、社会赞许或反向理解效应。相关方法局限见 [Pew 问卷设计指引](https://www.pewresearch.org/writing-survey-questions/) 和 [van Sonderen 等的反向措辞研究](https://journals.plos.org/plosone/article?id=10.1371/journal.pone.0068967)。

20 位人物的参考答卷围绕既有简介与作品主题作设计性选择，直接保存 32 个整数回答，再由同一模型计算坐标。它们不是历史人物真实作答，也不是从原著量出的数字；文学作者映射作品关注，不把角色言论当成作者立场。没有给坐标增加小数来强行制造差异。原型合法、自匹配与互不重复只证明程序可达，不等于历史准确或心理测量验证。

v4 答案单独保存；v2、v3 的答案和画像不能直接换算。本文件记录方法，网页无需增加用户已要求移除的声明。
