# Philome v3：八种思想关注的情境画像

设计审查：2026-10-28。本文件是重构提案，不把设计规则当作心理测量验证。v3 不能沿用 v2 的题目答案或人物坐标。

## 八轴的工作定义

| 索引 / 轴 | 在情境中更先关注什么 | 不应解释成什么 |
| --- | --- | --- |
| 0 经验求证 | 观察、尝试、核查具体证据，以判断什么可信 | 科学能力、实际行动的所有形式 |
| 1 概念思辨 | 定义、前提、推理及问题的结构 | 智商、知识量、所有认真思考 |
| 2 自主选择 | 保留并承担自己作选择的空间 | 自私、拒绝全部规则 |
| 3 共同关怀 | 他人的具体处境，以及怎样共同生活 | 从众、无条件牺牲自己 |
| 4 原则承诺 | 可以共同适用的边界、承诺与责任 | 死板、守一切旧规则 |
| 5 行动实践 | 下一步能作出的改变、尝试实施与承担后果 | 执行能力、哲学上的结果主义 |
| 6 内在省察 | 自身的情绪、欲望与过去经历如何影响判断 | 情绪强度、心理健康情况 |
| 7 诗性想象 | 借人物、故事、意象及想象理解复杂经验 | 文学天赋、艺术能力 |

这些是八个可区分的观察角度，不是被证明彼此独立的心理因素。“经验求证”问凭什么相信，“行动实践”问接下来改变什么；“共同关怀”问谁的具体处境，“原则承诺”问哪条边界；“内在省察”解释自身动机，“概念思辨”澄清问题本身。混合选项必须真的包含两类关注，不能仅为配平而加副轴。

## 最小题库结构

推荐 32 个日常情境，每题四个同样值得考虑的反应，选“你更可能先做哪一件”。每选项主关注 +2，副关注 +1。每题的 8 轴恰好各出现一次；整卷每轴主关注 16 次、副关注 16 次。

情境配置可分为四组，每组八题，但界面可以交错呈现以减少连续同类语境：

| 组 | 八个情境主题 |
| --- | --- |
| 判断问题 | 新学习方法、两位专家相反观点、社交媒体上的 AI 新闻、第一次研究陌生问题、反常观察、改变长期看法、阅读难懂的文本、展示一个新发现 |
| 与人共处 | 重订共同约定、提醒别人时的隐私边界、朋友与自己的分歧、资源有限的小组计划、许下的承诺、权威与自己的判断、公开讨论的表达、被忽略者的遭遇 |
| 自己的人生 | 工作选择与亲近者期待、别人不理解的兴趣、原计划失败、关系中的犹豫、忙碌背后的感受、回看一次错误、时间有限的人生、缺少现成目标时的投入 |
| 表达与改变 | 选一本想读的书、写一段重要表达、整理一次旅行、完成个人项目、面对不公平的日常、理解陌生作品、想象未来生活、参与一个共同活动 |

不能把题目主题当作正确轴：例如“研究问题”四个反应都须合理，不能把只有经验选项写得像认真做事；伦理题不能把其他选项写成冷漠。避免一个选项字数、具体程度或道德吸引力明显胜出。副轴要有对应文字依据。

配平可先使用八节点 round-robin 的 7 组配对，各组选项是四对不同的轴：

```text
0: (0,7) (1,6) (2,5) (3,4)
1: (0,6) (7,5) (1,4) (2,3)
2: (0,5) (6,4) (7,3) (1,2)
3: (0,4) (5,3) (6,2) (7,1)
4: (0,3) (4,2) (5,1) (6,7)
5: (0,2) (3,1) (4,7) (5,6)
6: (0,1) (2,7) (3,6) (4,5)
```

前 16 题遍历 `0..6,0..6,0,1`；每对的主副方向可按题号与选项号交错。后 16 题用不同主题但复用配对，主副方向全部相反，即保证每轴 16 主 / 16 副。该表只是作者的覆盖工具；若难以写出自然选项，应调整配对并重新检查机会数，而不是保留牵强条目。每个选项有稳定 ID；显示顺序按题轮换或稳定随机，与答案存储的 ID 分离，不能长期固定某字母对应某轴。

## 计分与雷达

完整答卷总积分恒为 `32×3=96`。每轴最多可获得 `16×2+16×1=48`，因此 `profile[d]=raw[d]/48`。八轴合计恒为 2、平均为 .25，这来自设计结构；全体都很高或都很低不可能发生，不能据此作人群比较。雷达与思想家使用同一个固定标尺；可以显示 0–48 的“关注积分”或其线性换算，但不按个人最高轴硬拉满、不用幂函数把轻微差别做尖，也不称百分位或能力分。

网页一句图例即可：“每条轴表示你在这些情境里更先关注什么。”更详细的方法说明放本文档。均匀轮廓是可能且合理的回答结果，不得承诺每个人都有尖锐分型。原始点数、覆盖次数和距离都是程序描述，不是因子结构、信度或统计置信度。

固定总分的多维强制选择属于 ipsative（个人内部相对比较）计分；八轴不能因为名称分开就称统计独立。Brown 与 Maydeu-Olivares 的原始研究讨论了这种传统计分的限制，以及在适当数据与模型条件下的替代方法。本项目没有拟合其 IRT 模型，不能借该论文声称已经解决限制。[论文与作者自存稿](https://kar.kent.ac.uk/30530/)。题目措辞和选项形式仍需预试；替代陈述也不能自动消除社会赞许等偏差。[Pew 问卷设计指引](https://www.pewresearch.org/writing-survey-questions/)。

## 人物原型：先有解释，再有可达坐标

不能把旧 8 个双极向量平移到 0–1。建议每个人先写一个 v3 的 32 题“设计性参考答卷”，从具体选项计算坐标，使其位于真实可达集合。参考答案用稳定选项 ID，并附最能说明该人物的 3–5 个场景理由。原著及旧 `matching-notes.md` 支持定性主题，不支持精确数值。

下表是初始主题提示，不是人物真实作答，也不是强迫配出差异的命令；实现者应逐题检查语义，而不是单按前三轴贪心选项。

最低检查：20 个参考答卷都合法；其计分与各自原型完全相同；不同人物坐标不重复；参考答卷自身最近匹配包含该人物。若撞点，先检查题库能否表达两人的主题区别，再改相应参考情境；不凭空给某维加 .01 来通过测试。用同一计分空间的欧氏距离即可，不将相似度说成“有几成是某人”。可达性是构造检查，不是历史准确性或受试者验证。

v2 存档仍可保留旧结果，但 v3 必须重新作答，不按新题重放旧答案。导出报告需带题库版本，避免两个版本的八轴被误当同一模型。
