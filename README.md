# coiHan · 个人太阳系

在线主页：[coihan.github.io](https://coihan.github.io/)。

首页以太阳系为主要画面：太阳位于左侧，八大行星由近及远排列，通过星球进入独立页面：

| 星球 | 页面 | 内容 |
| --- | --- | --- |
| 水星 · 关于我 | `/worlds/about.html` | 韩广路 / Jack，山东大学人工智能研一，研究兴趣为具身智能 |
| 金星 · 兴趣与好奇 | `/worlds/curiosity.html` | 从问题和不同视角出发 |
| 地球 · 生活影像 | `/worlds/interests.html` | 旧站影像素材 |
| 火星 · 项目 | `/worlds/projects.html` | [philome](https://coihan.github.io/philome/)，64题、8维、20位思想家 |
| 木星 · 研究方向 | `/worlds/research.html` | 具身智能与想进一步理解的问题 |
| 土星 · 想法实验室 | `/worlds/lab.html` | 留给未来的小想法和原型 |
| 天王星 · 成长轨迹 | `/worlds/growth.html` | 当前学习阶段和接下来的方向 |
| 海王星 · 联系我 | `/worlds/contact.html` | 用户确认的公开邮箱与 GitHub |

星球点击后有聚焦过渡，再进入对应页面。页面支持直接访问与返回，减少动态偏好下提供简化效果。网站使用静态 HTML、CSS、JavaScript 与本地托管的 Three.js，不依赖服务端或外部 CDN。

大小与间距做了适合页面阅读的压缩，保留真实顺序和大致的大小关系。轨迹以太阳为中心显示局部弧线，运动保留近处较快、远处较慢的关系。尺寸与位置参考 [NASA 行星尺寸与顺序](https://science.nasa.gov/solar-system/planets/planet-sizes-and-locations-in-our-solar-system/)。纹理与渲染库的来源见 [素材署名](https://coihan.github.io/credits.html)。
