# coiHan · 私人工作台

在线主页：[coihan.github.io](https://coihan.github.io/)。

一张可以走近的书桌，一台可以打开的个人电脑。韩广路 / Jack 的个人档案、项目、生活相册与联系方式收在电脑桌面中。philome 保持独立项目，地址仍为 `/philome/`。

## 体验

- 原创程序化三维书桌：CRT 电脑、键盘、书本、绿植、台灯、相框与小物件。
- 点击物件或使用下方导航，镜头走近电脑，在显示器内部操作复古桌面，保留三维显示器边框。
- 鼠标经过空白处可以平滑改变三维观察角度；画面静止时暂停重复渲染。
- 桌面与椅子适当加高；转椅保留初版样式，增加坐垫缝线、升降杆与双滚轮细节。
- 桌面窗口支持拖动、最小化、最大化、关闭与再次打开；手机端提供适配窗口。
- 日光与夜晚切换；声音默认关闭；支持键盘与减少动态偏好。
- 电脑界面按显示器内部尺寸重排；浏览器前进、后退与视角变化同步。
- 图形场景不可用时自动提供轻量入口，仍能访问全部个人内容。

## 内容

个人信息仅使用本人确认的内容：韩广路 / Jack，山东大学人工智能研一，研究兴趣是具身智能。项目展示以已有的 philome 为主，没有虚构论文、奖项、经历或文章。照片沿用本人旧站素材，只描述画面。

## 本地预览与部署

这是静态 HTML、CSS 和 JavaScript 网站，无后台或构建步骤。使用任意静态 HTTP 服务预览目录即可。根目录部署到 GitHub Pages；`.nojekyll` 保证资源直接托管。

发布首页时保留发布时刻远端的 `philome/` 子树，避免覆盖其独立更新。`publish-base.json` 是本地发布审查记录，不属于网站部署内容。
