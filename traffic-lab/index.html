ABOUT THIS PROJECT

FlowLab.

面向课程期末演示的智能流量分析 Web 应用。

涵盖探索性时空分析、K-means 区域聚类、滑动窗口任务构建、12 种参数可调预测算法、真实训练监控与测试集评估。

模型包括统计基线、指数平滑、自回归、岭回归、近邻回归与小型神经网络。复杂模型在浏览器内训练，结果用于课程实验，不代表生产系统精度。

地理边界来自原始数据；流量单位未在数据中注明。聚类标签仅描述流量节律。留出测试集为历史数据末尾连续区间，未参与模型训练。
