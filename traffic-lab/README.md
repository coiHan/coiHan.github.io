# FlowLab · 智能流量分析

课程期末项目，可直接交互的浏览器应用。

在线访问：https://coihan.github.io/traffic-lab/

## 功能

- 济南 4G 下行流量真实数据：148 区域、2024-07-28 至 2024-08-25，696 小时。
- 区域时间曲线、24小时平均轮廓、可拖动时间的真实地理区域快照。
- K-means 聚类（2–7簇），以区域的标准化24小时平均曲线为特征，固定初始化，显示收敛轮数。
- 输入长度4–168小时、输出长度1–72小时，可设核心参数。
- 12种实际实现算法：朴素预测、历史均值、移动平均、加权移动平均、季节朴素、阻尼趋势、简单指数平滑、Holt、自回归AR、岭回归、KNN、MLP。
- 真实训练/回测进度及RMSE。统计法不需要梯度训练，显示训练段内滚动回测；KNN显示留一验证；AR、Ridge、MLP显示训练损失。
- 连续末尾测试集不参加训练；支持MAE、RMSE、sMAPE、R²，以及预测和评估CSV导出。

## 运行

直接双击 `index.html`，或在当前目录运行 `python3 -m http.server 4178`，打开 http://localhost:4178 。没有外部运行依赖或密钥，全部计算在浏览器内执行。

## 数据说明

来源为课程提供 `data(1).7z` 中的 `zte_4g_down.region.csv` 与相应GeoJSON。15分钟原始观测按小时取四次均值，四舍五入为整数，零值保留。原始文件未标记流量单位，界面不推定为MB/GB。地图采用原始区域多边形简化展示。米兰数据可通过页面右上角切换载入；Trentino数据保留于本地，未载入本演示。

聚类标签描述流量模式，并非经外部地理资料验证的功能区分类。算法是面向课程实验的轻量实现，训练集误差不能替代独立测试集误差。12模型对比使用相同区域、输入长度、输出长度与时间划分，模型参数使用各自默认值。

## 文件

`index.html`、`styles.css`、`app.js`、`models.js`、`data.js`。原始资料与预处理脚本保留于本地期末项目文件夹，未将其他本地项目资料发布。

## 米兰数据集

页面右上角可切换济南与米兰。米兰数据来自课程归档 milano_traffic_nid.csv 与 milano.geojson，保留全部88个区域，以原始10分钟观测的每小时均值展示，流量单位按原始文件保留。地图、聚类和全部12种预测算法对两组数据通用。米兰数据首次切换时才加载；每次切换清空当前实验记录，避免跨城市误差混比。支持链接参数 `?dataset=milan` 直接打开米兰。
